# AI World Hackathon 2026

Repository: https://github.com/wkao1234/aiworldhackthon26

## Workflow

1. The orchestrator assigns requirements.
2. The coder implements changes on branches and opens pull requests.
3. The reviewer checks each pull request against the requirements and reports decisions in its chat.
4. The orchestrator coordinates any fixes.

The coder and reviewer use the same GitHub account (`wkao1234`), so review decisions are reported in chat rather than submitted as formal GitHub approvals on that account's pull requests.
